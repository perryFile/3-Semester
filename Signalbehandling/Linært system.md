Hvis vi har input **x_1**  som går gennem vores filter **h** så får vi **y_1**. Hvis vi lader **x_2** gå gennem **h** så får vi **y_2**. Hvis vi siger **x_1** + **x_2** = **x_3** som vi lader gå gennem **h**, så får vi **y_3** som er det samme som **y_1** + **y_2** = **y_3**
