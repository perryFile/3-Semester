# Excalidraw Data

## Text Elements
MIR: "Microinstruction registre"
indeholder den instruktion der skal udføres. Feks hente data, lægge data sammen osv. ^AlaTDgOU

MBR: "Memory Buffer Register" holder instruktioner fra ISA, feks "IADD". Instruktionerne repræsenteres som 8 bit, 1 byte ^Rbe2Y0o2

MPC: "Micro program counter"
Bruges til at pege på den næste micro instruktion i "control store". I modsætning til PC vil den ikke "counte" op, men kan springe rundt afhængig af "JAMN AND N" og "JAMZ AND Z" ^WxZIlQN7

MAR: "Memory Address Register" indeholder den adresse som skal læses eller skrives til i memory ^MYov6CV4

MDR: "Memory data registre"
bruges til at gemme den data som bliver loaded ind fra MAR,  eller som skal skrives til den adresse MAR indeholder. 32 bit som læses eller skrives til memory. ^OcclZq74

Control store: Er registreret som indeholder den næste instruktion. ^Aq6h2Cnk

B-bus: Vælger ét register, der sender data ind mod ALU’en ^12fRDxnq

ALU: "Arithmetic logic unit. Der hvor tingene sker. Matematiske operationer bliver udført. ^fnNQHQvj

C-bus: Bus hvor data sendes tilbage til registre.  ^kEfOtwL9
