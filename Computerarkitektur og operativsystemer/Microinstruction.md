# Excalidraw Data

## Text Elements
MIR: "Microinstruction registre"
indeholder den instruktion der skal udføres. Feks hente data, lægge data sammen osv. ^AlaTDgOU

MBR: "Memory Buffer" holder én 8-bit byte hentet fra program-memory via PC/FETCH. feks "IADD". Instruktionerne repræsenteres som 8 bit, 1 byte. Påvirker MPC til hvilken instruktion den skal hente fra control store. ^Rbe2Y0o2

MPC: "Micro program counter"
Bruges til at pege på den næste micro instruktion i "control store". I modsætning til PC vil den ikke "counte" op, men kan springe rundt afhængig af "JAMN AND N" og "JAMZ AND Z" ^WxZIlQN7

MAR: "Memory Address Register" indeholder den adresse som skal læses eller skrives til i memory ^MYov6CV4

MDR: "Memory data registre"
data som bliver læst fra memory ved adressen i MAR. 32 bit som læses eller skrives til memory. ^OcclZq74

Control store: Hukommelsen der indeholder alle microinstructions. MPC vælger hvilken der skal hentes ^Aq6h2Cnk

B-bus: Vælger ét register, der sender data ind mod ALU’en ^12fRDxnq

ALU: "Arithmetic logic unit. Der hvor tingene sker. Matematiske operationer bliver udført. ^fnNQHQvj

C-bus: Bus hvor data sendes tilbage til registre.  ^kEfOtwL9

JMPC: Er kontrolbit i MIR som bestemmer om MBR skal påvirke MPC. MPC=NEXT_ADDRESS OR MBR ^Q517Z3ZM

JAMN: Sammen med N flaget fra ALU påvirker også MPC til at springe rundt i control store ^SVVfTubt

JAMZ: Sammen med Z flaget fra ALU påvirker også MPC til at springe rundt i control store ^jY4mIHwZ

 Memory ^ez6KifwF

PC: peger på adressen på næste IJVM-byte/opcode i Method Area ^CucAoVvD
